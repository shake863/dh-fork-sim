# 开发记录

## 2026-09-27 · 第一轮（Claude Code 会话）

用户需求按顺序：

1. 做一个可交互的演示，学习速降前叉的压缩原理。
   - 先用 Node 写了物理原型，调好默认参数后再做界面。
   - 界面：前叉剖面（可拖动）+ 弹簧力、阻尼力、行程三张图 + 5 种地形 + 参数滑块。
2. 问倒置前叉原理是否一样：结论是原理相同、结构不同（见 knowledge.md 第 2 节）。之后加了“正置 / 倒置”切换，以及“标出簧下部分”高亮。
3. 加 Fox GRIP 和 GRIP2 的效果与差别：
   - 阻尼改成可切换的参数组，回弹也拆成高低速两段。
   - 阻尼图加灰带，显示最近拖动的旋钮的调节范围。
   - 加“峰值冲击力”指标。
   - 行程图加灰线，保存上一次运行的结果，方便对比。
4. 保存成网页：
   - 做成独立 HTML，自带 CSS 变量和深色模式、窄屏布局。
   - 新建公开仓库 `shake863/dh-fork-sim`，开启 GitHub Pages（legacy，`main` 分支根目录）。
   - 已在浏览器中验证线上页面正常。

### 调参记录

以下数据用 Node 原型得出。原型当时用的是旧阻尼映射，与现在 GRIP2 的默认映射接近，但不完全相同。

- 默认 80 kg、100 psi、2 个垫片：sag ≈ 41 mm（20%），200 mm 处弹簧力约 2.9 kN，静载约 377 N。
- 落差 `H = 0.7 m`，最大行程随垫片数的变化：

  | 垫片数 | 最大行程 |
  |---|---|
  | 0 | 205 mm（触底） |
  | 1 | 203 mm（触底） |
  | 2 | 196 mm |
  | 3 | 186 mm |

  `H = 1.0 m` 时怎么调都会触底，所以最终选了 0.7 m。
- 碎石路：最初设定（7 m/s、较陡的石块）轴速达到 8 m/s，不合理。改成 5 m/s、石块长 0.35–0.75 m、高 25–80 mm 后，最大轴速约 2.9 m/s，最大行程约 130 mm。回弹调到最慢时能明显看到打包。
- 方边：6 m/s、12 cm、爬升距离 0.2 m，峰值轴速约 5 m/s，最大行程约 146 mm。
- 急刹：LSC 最软和最硬时最终下沉深度差不多（约 93 mm，由弹簧决定），但最硬时下沉明显更慢。
- 垫片等效容积最初是每个 15 mm，效果太弱，后来改成每个 25 mm，最多 4 个。

## 2026-09-27 · 第二轮：Santa Cruz 整车（bike.html）

用户需求：做一个“三条裤子”的整车压缩效果。“三条裤子”是国内骑友对 Santa Cruz 的外号。一开始误以为是语音识别错误，问过用户后才确认。

### 查到的公开数据（V10.8）

- 后行程 208 mm，避震器 250×75 mm，平均杠杆比约 2.77。
- 官方说杠杆曲线比较线性、轻微渐进，是为钢圈避震优化的。
- 前叉行程 203 mm，头管角约 63°。S–L 码前后轮不同尺寸（MX），XL 码两轮都是 29 寸。
- 各尺码原厂弹簧 450–600 lb。

来源：Pinkbike 的 V10 首发文章、Santa Cruz 官方 V10.8 支持页、geometrygeeks。没有找到逐点的杠杆比数据。

### VPP 几何怎么来的

用 Node 脚本对四连杆做随机搜索加局部优化，要求如下：

- 后行程 208 mm 时，避震压缩 75 mm。
- 杠杆比从约 3.0 线性降到约 2.55。
- 两根连杆反向转动。
- 轮轴轨迹呈 S 形：先往后约 8–11 mm，再往前回。
- 连杆转点在五通和立管附近，避震器前端在下管上。

第一轮搜出来的下连杆垂到离地只有 17 cm，第二轮避震器前端悬在下管下方约 20 cm，加了位置约束后第三轮才得到合理的几何。结果写在 `GEO` 里：杠杆比 2.97 → 2.51，轮轴最多往后约 11 mm。搜索脚本保存在 `tools/vpp-search.js`（运行 `node tools/vpp-search.js`，每次随机结果不同，约需 1–2 分钟）。这是示意几何，不是 Santa Cruz 的真实图纸。

### 整车调参

- 落地一开始按 0.7 m 算，后轮怎么调都触底。原因有两个：钢圈弹簧是线性的、杠杆比渐进不多，所以储能有限；而模型里车手是刚体，腿不吸收冲击。
- 先加了末端 7 mm 的缓冲胶，还是触底。最后改成等效 0.45 m 平落，默认 450 lb 不触底（后轮约 198–201 mm），350 lb 会触底。
- 其他场景的结果：
  - 方边冲击：前叉 139 mm、后轮 151 mm，俯仰在 −7.9° 到 +6.1° 之间。
  - 碎石路：约 122 / 125 mm；回弹调到最慢时约 149 / 146 mm，能看到打包。
  - 急刹 0.5 g：低头 2.6°，后轮负载最低约 142 N。
- 核对方法：在浏览器控制台里对页面直接同步调用 `reset(sc)`，再循环 `step(0.0003)`，不要用定时器等动画。

### 界面

- 侧视图画了骑手的火柴人，方便看出车身俯仰。
- VPP 的两根短连杆在全车比例下太小，所以在左上角加了“连杆放大”窗，里面显示虚拟转点。窄屏时画布顶部会额外留出放大窗的高度。
- 前叉页顶部加了到整车页的链接。

## 以后可以做的方向

- 给车轮加质量（簧下质量），让倒置结构“簧下更轻、贴地更好”能在数值上体现出来。
- 空气弹簧和钢圈弹簧可切换。
- 加入 Fox GRIP X / GRIP X2 等更新的阻尼。加之前要先核实规格。
- 把物理部分拆成可以在 Node 里跑的回归检查，避免以后改参数时破坏上面的调参目标。
- 整车页：
  - 加入 anti-squat / anti-rise（踩踏和刹车时后避震的额外反应）。
  - 让车手用腿吸收冲击（车手与车架之间加弹簧阻尼），这样落差可以用真实高度。
  - 加入不同后避震结构（单摆臂、Horst 四连杆、高位转点）和 VPP 对比。
