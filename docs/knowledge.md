# 速降前叉压缩原理 · 学习笔记

配合演示页 https://shake863.github.io/dh-fork-sim/ 使用（前叉页和整车页）。模型是简化的，数值只说明趋势。

## 1. 两套系统：弹簧和阻尼

前叉压缩时有两套东西同时在工作：

- **弹簧**决定“最终能撑住多大的力”。它的力**只看压了多深**。
- **阻尼**决定“压得多快、回得多快”。它的力**只看轴速**（前叉被压缩或伸展的速度）。

### 空气弹簧

- **正气室**：前叉往下压，气室变小，气压升高，推力变大。气体越压越硬，所以力-行程曲线往上翘，叫“渐进”。同样 sag 的钢圈弹簧则是一条直线。
- **负气室**：在活塞下方。压缩时它的容积变大、气压下降，抵消一部分正气室的力，所以行程开头特别软、特别顺。
- **容积垫片**：塞进正气室占掉一部分空气。行程前段几乎不变，末段明显变硬，主要用来防触底。
- **气压**：主要决定 sag（车手静止骑在车上时前叉的下沉量）。速降一般设在 15–20%。

### 阻尼

- **LSC 低速压缩**：轴速很低时，油只能从针阀的小孔过。管的是急刹点头、过弯下压、踩踏晃动这类慢动作。
- **HSC 高速压缩**：轴速超过开启点后，油把阀门上的一叠薄钢片（shim）顶弯，打开大通道。管的是方边、石块、落地这类瞬间冲击。
- **回弹**：前叉伸回来时起作用。太快会弹手、不跟地；太慢会在连续冲击里来不及伸回，越压越深，叫“打包”（packing）。

## 2. 正置和倒置（USD）前叉

压缩原理完全一样，空气弹簧和阻尼器的工作方式都不变。倒置只是把结构上下颠倒。

| | 正置前叉 | 倒置前叉 |
|---|---|---|
| 上面是什么 | 细的内管，夹在肩盖里 | 粗的外管，夹在肩盖里 |
| 下面是什么 | 粗的外管，连着车轴 | 细的内管，连着车轴 |
| 左右腿怎么连 | 外管之间有拱桥连在一起 | 下面没有拱桥，两根内管各自独立 |
| 跟着车轮上下跳的部分（簧下质量） | 较重（外管加拱桥） | 较轻（只有细内管） |
| 前后方向刚性 | 一般 | 更好（粗管在受弯最大的位置） |
| 扭转刚性 | 好，拱桥把两条腿锁在一起 | 差，只靠车轴把两条腿连起来 |
| 油封润滑 | 油封在上方，靠飞溅润滑 | 油封在下方，一直泡在油里，初段更顺 |
| 怕什么 | 内管在上面，不容易被石头打到 | 内管露在最下面，容易被石头打伤；油封漏油会滴到刹车碟上 |

摩托车几乎都用倒置，因为车轴粗、轮子硬，扭转问题基本被吃掉了。山地车车轴细、轮子软，没有拱桥的倒置前叉转向时会扭，所以主流速降叉（Fox 40、RockShox Boxxer 等）都是正置双肩叉。Manitou Dorado、DVO Emerald 等倒置速降叉有忠实用户，但不是主流。

## 3. Fox GRIP 和 GRIP2

用户最初把 GRIP 叫作“G1”，官方叫法是 GRIP 和 GRIP2。

| | GRIP | GRIP2 |
|---|---|---|
| 压缩调节 | 1 个旋钮，高速和低速一起变 | 分开调：LSC、HSC |
| 回弹调节 | 1 个旋钮 | 分开调：LSR、HSR |
| 调节的效果 | 整条阻尼曲线一起抬高或降低 | 可以只改曲线的某一段 |
| 定位 | 简单，不容易调乱 | 可调范围大，适合讲究调校的车手 |

核心差别：用 GRIP 把压缩拧硬来抗点头，过方边也会跟着变硬、变冲；GRIP2 可以只拧硬 LSC 抗点头，同时让 HSC 保持软来吃方边。

注意：

- 演示里 GRIP2 的格数参照了常见的 HSC/HSR 约 8 格、LSC/LSR 约 18 格，但力的大小只是示意，不是 Fox 实测的阻尼曲线。
- 真车上的格数通常从全关（最硬）往回数，方向和演示里“越大越硬”相反。实际调车以说明书和 Fox 调校表为准。
- 不同年款和系列的 GRIP，压缩调节形式不同，有的是连续旋钮，有的是三档拨杆。演示里统一成一个压缩旋钮。

## 4. 推荐实验

1. **手动按压**：在前叉图上拖动。慢拖时红点在低速压缩段，快拖时跳到高速压缩段。松手看回弹。
2. **落差落地**：容积垫片调到 0 跑一次，会触底；调回 2–3 个再跑一次对比。
3. **碎石路**：回弹调到最慢（GRIP2 把 LSR 拉满），看行程曲线整体下沉，这就是打包。
4. **GRIP 和 GRIP2 对比**：
   - 选 GRIP，压缩拧到 10，分别跑急刹点头和方边冲击。点头被压住了，但方边的峰值冲击力也变大了。
   - 换成 GRIP2，LSC 拉到 18、HSC 调到 0，再跑这两个地形。点头照样压得住，方边的峰值冲击力明显更低，代价是行程用得更深。
   - 行程图里的灰线是上一次运行的结果，可以直接对比两次。
5. **落地后的回弹**：深压之后弹簧力很大，前叉会快速伸展，这时起作用的是 HSR。

## 5. 整车：前后悬挂一起工作（Santa Cruz V10 风格）

配合 [bike.html](../bike.html) 使用。“三条裤子”是国内骑友对 Santa Cruz 的外号，来自 Santa Cruz 的谐音。它的速降车叫 V10，后避震用的是招牌的 VPP（Virtual Pivot Point，虚拟转点）结构。

### 后避震的三个关键概念

- **杠杆比**：后轮上下走的距离 ÷ 避震器压缩的距离。V10.8 后轮行程 208 mm，避震器行程 75 mm，平均杠杆比约 2.77。杠杆比随行程越来越小，就叫“渐进”：越往后压，后轮越难压。钢圈弹簧本身是线性的，所以整车的渐进要靠连杆来实现。
- **虚拟转点**：VPP 用两根很短的连杆把后三角挂在前三角上，两根连杆反向转动。把两根连杆的延长线画出来，交点就是后三角这一瞬间的转动中心。它不是一个真实的轴，而且会随着行程移动，所以叫“虚拟”转点。
- **后轮轴轨迹**：后轮压缩时，轮轴不是单纯上下动，而是先往后、再往前，呈 S 形。一般认为，早段往后的轨迹让后轮在撞方边时更容易“让开”冲击。

### 整车才有的现象

- **俯仰**：前后悬挂一个压、一个伸，车身就会前后倾。
  - 刹车时重心前移，前叉下沉、后避震伸长，车头往下点。
  - 撞方边时前轮先撞、车头抬起；约 0.2 秒后后轮再撞，车头被压回去。
- **前后轮时间差**：速度 5–6 m/s、轴距 1.27 m 时，后轮大约晚 0.2–0.25 秒碰到同一个障碍。
- **sag 前后不同**：速降车常见前 15–20%、后 30–35%。后轮下沉得多，所以静止时车身会微微抬头。
- **负载转移**：急刹时后轮负载可能降到很小，这时后轮容易打滑或跳动。真车还会受车架 anti-rise 设计的影响，演示里没有模拟。

### 推荐实验

1. **手动按压**：在车头附近往下拖，主要压前叉，车身低头；在座位附近往下拖，主要压后避震，车身抬头。
2. **急刹点头**：看“前 / 后轮负载”两个数字的变化，以及俯仰角。
3. **方边冲击**：看行程图里蓝线（前）先跳、红线（后）后跳，还有右上图的红点沿 S 形轨迹移动。
4. **落差落地**：后弹簧从 450 lb 换成 350 lb，后避震会触底。对比前叉，钢圈弹簧加上轻微渐进的杠杆比，在末段的储能不如渐进的空气前叉。
